# تطبيق تجميع مشتريات الموردين

تطبيق Windows Desktop باللغة العربية لإدخال طلبيات الفروع يدويًا، ثم تجميع المنتجات حسب المورد وإنشاء قائمة شراء قابلة للمعاينة والطباعة.

![.NET 8](https://img.shields.io/badge/.NET-8.0-512BD4) ![WPF](https://img.shields.io/badge/UI-WPF-blue) ![SQLite](https://img.shields.io/badge/DB-SQLite-003B57)

## المميزات

- لوحة رئيسية بإحصائيات سريعة عن الطلبيات والموردين.
- إدخال طلبيات الفروع مع إكمال تلقائي لأسماء المنتجات والموردين.
- قواعد إسناد تلقائي تربط المنتج بالمورد والوحدة حسب كلمة مفتاحية.
- تذكّر آخر وحدة استُخدمت لكل منتج.
- بحث في الطلبيات بالفرع أو الملاحظات، وفلترة بنطاق تاريخ.
- قائمة شراء مجمّعة لكل مورد، مع معاينة وطباعة وحفظ كصورة PNG.
- تقارير شهرية لمشتريات كل مورد.
- قاعدة بيانات SQLite محلية مع نسخة احتياطية يومية تلقائية.
- لا يحتاج إنترنت ولا خادم.

## التحميل

حمّل `SupplierPurchases.exe` من آخر نسخة في صفحة [Releases](https://github.com/msalah-kw/supplier-purchaes/releases/latest) وشغّله مباشرة. النسخة لا تحتاج تثبيت .NET.

## المتطلبات

- Windows 10 أو أحدث
- [.NET SDK 8](https://dotnet.microsoft.com/download/dotnet/8.0) للتطوير والبناء فقط. النسخة المنشورة `self-contained` لا تحتاج تثبيت .NET.

## التشغيل أثناء التطوير

```powershell
git clone https://github.com/msalah-kw/supplier-purchaes.git
cd supplier-purchaes
dotnet run
```

## إنشاء ملف EXE

شغّل `rebuild.bat` من مجلد المشروع. أغلق البرنامج قبل التشغيل.

الناتج ملف واحد فقط `SupplierPurchases.exe` في المجلد الرئيسي للمشروع، يحتوي runtime وكل المكتبات، ولا يحتاج أي ملفات بجانبه. السكربت يحذف مجلدات البناء المؤقتة `bin` و`obj` بعد الانتهاء.

أو نفّذ الأمر يدويًا (إعدادات الملف الواحد موجودة في `SupplierPurchases.csproj`):

```powershell
dotnet publish -c Release -o .\out
```

## مكان حفظ البيانات

يحفظ التطبيق قاعدة SQLite محليًا في:

```text
%LOCALAPPDATA%\SupplierPurchases\supplier_purchases.db
```

ويحفظ نسخة احتياطية يومية داخل:

```text
%LOCALAPPDATA%\SupplierPurchases\backups
```

## طريقة الاستخدام المختصرة

1. افتح `طلبية جديدة`.
2. أدخل اسم الفرع وتاريخ الطلبية.
3. أضف المنتجات مع الكمية والوحدة واسم المورد.
4. احفظ الطلبية.
5. افتح `قائمة شراء` واختر المورد.
6. اضغط `إنشاء القائمة` لمشاهدة التجميع.
7. استخدم `معاينة الطباعة` أو `طباعة مباشرة` أو `حفظ كصورة`.

## صورة طلب الشراء

زر `حفظ كصورة` يحفظ طلب الشراء كصورة PNG:

- الجدول فيه: م، اسم المنتج، الكمية، الوحدة.
- أسفل الجدول سطر `إجمالي الحبات` وسطر `إجمالي الكروز`.
- حجم الصورة يناسب المحتوى: العرض ثابت، والارتفاع ينتهي بعد آخر سطر بدون فراغ، سواء كان الطلب صنفين أو مئة صنف.
- الصورة بضعف دقة الشاشة، فتبقى واضحة عند التكبير على الجوال.

## التقارير الشهرية

اختر السنة والشهر من شاشة التقارير الشهرية. قائمة السنوات تُبنى تلقائيًا من الطلبيات المحفوظة مع السنة الحالية.

الشاشة تعرض ملخص مشتريات كل مورد خلال الشهر. زر `معاينة وطباعة` يعرض قائمة المورد المجمّعة للشهر، ويمكن طباعتها أو حفظها كصورة.

## البحث في الطلبيات

في شاشة `الطلبيات`:

- اكتب في خانة البحث جزءًا من اسم الفرع أو الملاحظات. البحث يتجاهل فروق الكتابة العربية، وكل الكلمات المكتوبة يجب أن تظهر.
- حدد `من تاريخ` أو `إلى تاريخ` أو كليهما. الحدود شاملة.
- زر `مسح الفلتر` يعرض كل الطلبيات من جديد.

## إدخال المنتجات بالكيبورد

حقول اسم المنتج واسم المورد تعمل بالإكمال التلقائي مباشرة داخل الجدول بدون الدخول في وضع تعديل:

- ابدأ الكتابة لتظهر قائمة الاقتراحات، والبحث يتجاهل الفروق بين (أ/ا) و(ي/ى) و(ة/ه) والتشكيل والأرقام العربية.
- `سهم لأسفل` و`سهم لأعلى` للتنقل داخل القائمة، و`Page Up/Down` للتنقل السريع.
- `Enter` لاختيار العنصر المميز، ثم `Enter` مرة أخرى للانتقال إلى الحقل التالي.
- `Esc` لإغلاق القائمة والاحتفاظ بما كتبته كاسم جديد.

## العمليات الجماعية داخل الطلبية

كل سطر في جدول الطلبية له مربع اختيار، ومربع الاختيار في رأس العمود يحدد كل الأسطر. بعد التحديد يمكن من شريط العمليات:

- ضبط الوحدة (`حبه` أو `كرز`) لكل الأسطر المحددة دفعة واحدة.
- إسناد مورد واحد لكل الأسطر المحددة دفعة واحدة.
- `تطبيق قواعد الإسناد` لملء الموردين تلقائيًا.
- حذف كل الأسطر المحددة دفعة واحدة.

## قواعد الإسناد التلقائي

من شاشة `قواعد الإسناد` يمكن ربط كلمة مفتاحية بمورد، مثل: أي منتج يحتوي اسمه على `اير بار` يُسند إلى المورد `البيرق`.

- يمكن اختيار `الوحدة` للقاعدة (`حبه` أو `كرز`) لضبط وحدة المنتج تلقائيًا أيضًا، أو تركها `بدون تغيير`.
- تُطبَّق القاعدة تلقائيًا بمجرد كتابة اسم المنتج: المورد يُملأ إذا كان الحقل فارغًا، والوحدة تُضبط فقط عند كتابة اسم منتج جديد أو تغييره، حتى لا يُلغى أي اختيار يدوي.
- عند تطابق أكثر من قاعدة تفوز القاعدة ذات `الأولوية` الأعلى، ثم الكلمة المفتاحية الأطول.
- زر `تطبيق قواعد الإسناد` داخل الطلبية يطبّق المورد والوحدة من القواعد على الأسطر المحددة، أو على كل سطر بدون مورد إذا لم يتم تحديد شيء.
- تُحفظ التعديلات على القواعد تلقائيًا.

## تذكّر وحدة المنتج

عند حفظ الطلبية يحفظ البرنامج وحدة كل منتج. عند كتابة نفس المنتج في طلبية جديدة تُضبط وحدته تلقائيًا على آخر وحدة استُخدمت.

- وحدة قاعدة الإسناد تتقدم على الوحدة المحفوظة.
- الوحدة تُضبط فقط عند كتابة اسم منتج جديد أو تغييره، فلا يُلغى اختيارك اليدوي.

## إدارة الموردين والمنتجات

- شاشة `الموردون`: تعديل اسم المورد (يُحدَّث في كل الطلبيات السابقة وفي قواعد الإسناد)، أو حذف مورد. لا يمكن حذف مورد مستخدم في طلبيات محفوظة حفاظًا على البيانات، ويمكن تعديل اسمه بدلًا من ذلك.
- شاشة `استيراد المنتجات`: بحث سريع، وتحديد أكثر من منتج للحذف دفعة واحدة، وتعديل أو حذف أي منتج منفردًا.
- قائمة المنتجات الجاهزة تُضاف مرة واحدة فقط عند أول تشغيل، فلا تعود المنتجات المحذوفة بعد إعادة تشغيل البرنامج.

## قواعد التجميع

- يتم جمع الكميات عندما يتطابق اسم المنتج واسم المورد والوحدة.
- إذا اختلفت الوحدة، يظهر المنتج كسطر منفصل.
- يتم تجاهل المسافات الزائدة في المقارنة والحفظ.
- أسماء المنتجات والموردين تحفظ تلقائيًا لتظهر كاقتراحات لاحقًا.

## بنية المشروع

```text
Controls/AutoCompleteTextBox.xaml   حقل الإكمال التلقائي مع التنقل بالكيبورد
Data/AppDatabase.cs                 كل عمليات SQLite والنسخ الاحتياطي
Data/ArabicText.cs                  تطبيع النص العربي للبحث والمطابقة
Data/OrderFilter.cs                 البحث والفلترة في قائمة الطلبيات
Data/OrderItemAutoFill.cs           تعبئة المورد والوحدة تلقائيًا لسطر الطلبية
Data/PurchaseTotals.cs              إجمالي الكميات لكل وحدة أسفل الفاتورة
Data/ProductSeeder.cs               قائمة المنتجات الجاهزة عند أول تشغيل
Data/SuggestionSource.cs            تصفية سريعة للاقتراحات أثناء الكتابة
Data/SupplierRuleEngine.cs          مطابقة قواعد الإسناد التلقائي
Models/                             نماذج البيانات المعروضة في الشاشات
MainWindow.xaml.cs                  التهيئة والتنقل بين الشاشات وتحميل البيانات
MainWindow.<Screen>.cs              منطق كل شاشة في ملف مستقل (OrderEditor, Orders, Purchase, ...)
MainWindow.Printing.cs              بناء التقارير والطباعة والحفظ كصورة
MainWindow.Dialogs.cs               رسائل التنبيه والتأكيد ونافذة إدخال النص
tests/SupplierPurchases.Tests/      اختبارات xUnit
logo.ico                            أيقونة البرنامج
schema.sql                          مخطط قاعدة البيانات (مرجع)
rebuild.bat                         بناء نسخة EXE بضغطة واحدة
```

## الاختبارات

```powershell
dotnet test tests/SupplierPurchases.Tests
```

الاختبارات تغطي تطبيع النص العربي، ومطابقة قواعد الإسناد، والتعبئة التلقائية للمورد والوحدة، وفلترة الطلبيات، وعمليات قاعدة البيانات مثل التجميع وترقية الجداول القديمة. اختبارات قاعدة البيانات تعمل على ملف مؤقت ولا تلمس بياناتك.
